## 🐛 发现的问题清单

### 🔴 严重问题 (P0)

#### 1. 日志系统不一致 - ExtremeOptimizedGraph3D
**位置**: `src/components/ExtremeOptimizedGraph3D.tsx`  
**问题描述**: 
- 第149行: `console.warn('Error rendering extreme relationship:', error);`
- 第207行: `console.warn('Error handling extreme node click:', error);`
- 使用了 `console.warn` 而非统一的 `logger.warn`

**影响**: 
- 日志不统一，难以追踪问题
- 无法在日志面板统一管理
- 可能遗漏重要警告

**修复方案**: 
```typescript
// 替换为
import { logger } from '@/utils/debugLogger';
logger.warn('Error rendering extreme relationship:', error);
```

**状态**: 🔴 待修复

### 🟡 中等问题 (P1)

#### 3. 实体采样逻辑可能丢失关键数据
**位置**: `src/components/ExtremeOptimizedGraph3D.tsx` 第115-117行  
**问题描述**:
```typescript
const finalRenderEntities = isExtremeDataset 
  ? filteredEntities.filter((_, index) => index % 3 === 0) 
  : filteredEntities;
```
使用固定步长3进行采样，可能跳过重要的实体

**影响**: 
- 用户可能看不到某些实体
- 搜索结果不完整
- 选中实体后关系线可能不对齐

**修复方案**: 
- 添加采样策略选择
- 记录被跳过的实体数量
- 提供"显示全部"选项

**状态**: 🟡 待评估

---

**位置**: `src/components/ExtremeOptimizedGraph3D.tsx` 第109行  
**问题描述**:
```typescript
const filteredRelationships = isExtremeDataset ? [] : relationships.filter(rel => {
```
