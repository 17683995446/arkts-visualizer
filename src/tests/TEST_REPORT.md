## 2. 前置动作

### 2.1 代码分层与架构分析
- **前端**: React 组件，路由系统
- **状态**: Zustand Store (`useGraphStore.ts`)
- **数据**: Mock数据生成器 (`mockData.ts`)
- **可视化**: Three.js + React Three Fiber (`OptimizedGraph3D.tsx`)
- **调试**: 集中式日志系统 (`debugLogger.ts`)

### 2.2 参数规则与边界条件提取
- 实体类型: `File`, `Class`, `Component`, `Method`, `Field`, `StateVariable`
- 关系类型: `CONTAINS`, `CALLS`, `IMPORTS`, `DEPENDS_ON` 等
- 位置坐标: (-1000, 1000) 安全范围，防止 Infinity/NaN

### 2.3 数据流梳理
1. 生成Mock数据 -> 存储到Zustand Store
2. 从Store获取实体和关系 -> 传递给3D可视化组件
3. 3D组件筛选可见实体 -> 渲染节点和连接线
