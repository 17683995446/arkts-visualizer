## 🎯 阶段四执行计划（按步骤）

### 第一步：基础验证（15分钟）
1. **打开开发服务器**
   - 访问 http://localhost:5173/
   - 确认首页正常加载
   - 检查浏览器控制台无错误

2. **基础功能测试**
   - 尝试默认（Small）数据
   - 选择实体，看高亮是否正常
   - 尝试搜索功能
   - 切换页面（Home/Graph/Analysis/Query）

### 第二步：渐进式数据集测试（30分钟）
1. **Small -> Large 切换**
   - 点击 Load Large Mock Data
   - 观察加载时间
   - 检查统计数据是否正确
   - 检查节点渲染

2. **Large -> Huge 切换**
   - 点击 Load Huge Mock Data
   - 观察 FPS 是否稳定
   - 检查交互是否流畅
   - 选择实体测试高亮

3. **Huge -> Extreme 切换**
   - 点击 Load Extreme Mock Data
   - 观察极端数据加载
   - 检查 ExtremeOptimizedGraph3D 是否启动
   - 检查性能是否稳定

### 第三步：混沌场景测试（45分钟）
1. **Chaos Test**
   - 点击 Load Chaos Test Data
   - 观察控制台警告日志
   - 检查渲染是否正常兜底
   - 测试实体选择功能

2. **Realistic Enterprise**
   - 点击 Load Realistic Enterprise Data
   - 测试完整企业级场景
   - 观察真实应用场景
   - 记录性能指标

3. **Ultimate Chaos**（终极混乱！）
   - 点击 Load Ultimate Chaos Data
   - 观察所有极端场景综合
   - 检查是否有崩溃
   - 检查兜底降级是否正常工作
   - 观察控制台日志输出

### 第四步：压力与稳定性测试（1-2小时）
1. **快速切换测试**
   - 在所有数据模式间快速切换（50-100次）
   - 观察内存占用
   - 检查是否有内存泄漏
   - 记录任何崩溃或异常

2. **长时间运行测试**
   - 保持 Extreme 数据页面运行 10 分钟
   - 观察 FPS 稳定性
   - 检查内存增长情况
   - 记录任何异常

3. **高频操作测试**
   - 快速选择/取消选择实体（100次以上）
   - 快速搜索/清除搜索（50次以上）
   - 快速切换页面（30次以上）
   - 观察系统稳定性

### 第五步：性能数据收集（30分钟）
1. **收集基准数据**
   - 各数据集加载时间
   - 各场景 FPS
   - 内存占用基准
   - 交互响应时间

2. **记录发现问题**
   - 渲染异常
   - 性能问题
   - 错误提示
   - 任何不正常行为
